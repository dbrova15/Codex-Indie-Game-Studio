# Приклади запитів

Замініть назви сцен/вузлів на фактичні. Надсилання цих запитів запускає модельну роботу.

## Спочатку прочитати контекст

> Використай $codex-indie-game-studio. Прочитай чинні AGENTS і наявну карту канону цього проєкту. Визнач потрібні для мого завдання сцени та скрипти. Поки файли не змінюй і гру не запускай.

## Мала правка UI

> Використай $codex-indie-game-studio. У scenes/menu.tscn зміни підпис StartButton на «Почати гру». Збережи ієрархію, signal bindings та інші Inspector overrides. Повідом, які перевірки фактично виконані.

## Знайти дефект

> Використай $codex-indie-game-studio. Після скидання лічильника UI показує старе значення. Прочитай state/UI модулі, знайди причину та дій за чинним AGENTS маршрутом. Додай регресію лише для непокритої поведінки; новий AutoLoad або залежність не потрібні.

## Оцінити готову зміну

> Використай $codex-indie-game-studio. Перевір зміну меню наявними засобами. Окремо звітуй parse/import, runtime, interaction, visual та Inspector. Непроведене познач NOT RUN; для ручної перевірки назви сцену, вузол, властивість і очікувану поведінку.
