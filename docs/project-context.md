# Канон цільової гри

Визнач підтверджений корінь гри з фактичного робочого cwd або явно названої цілі автора. Каталог встановленого плагіна містить інструкції й ресурси пакета; він не є коренем гри.

Використовуй чинні інструкції автора та посилання AGENTS/README гри. Якщо вони вже визначають карту канону — прочитай її. За відсутності явного binding перевір наявний `docs/codex-indie-game-studio/source-map.md` відносно кореня гри. Якщо його немає, прочитай тільки потрібні для задачі existing README/brief, `project.godot` і цільові сцени/ресурси/скрипти. Не скануй весь диск і не створюй карту автоматично.

Active/next action бери з наявних авторських посилань. Суперечливі checkpoints не об'єднуй мовчки; не створюй другого active. Для малої локальної правки відсутній неістотний checkpoint не є приводом створювати документи. Уточни конкретний невідомий факт тільки коли від нього залежить дія; канон навчальної гри не підставляється.

Виконуй чинний маршрут автора щодо складності, специфікації, дозволів та історії; пакет не визначає нових глобальних правил. Не перезаписуй AGENTS, README, карту або checkpoint заради встановлення плагіна. Якщо вже є project Skill чи інше активне джерело з тим самим призначенням, назви конфлікт перед залежною перевіркою; не вимикай, не перейменовуй і не замінюй чужий компонент автоматично.

Для перевірки Godot-результату використовуй [QA](qa.md). Походження інструкцій — у [provenance](provenance.md).
